## Personal Finance Manager

For my senior project at Lebanese University, I built a web app for tracking expenses, income, monthly budgets, and savings goals. The case study includes dashboard, analytics, and calendar screenshots using sample data.

The React and TypeScript interface calls a Node.js and Express API backed by six related MySQL tables. Each user can set budgets by category, receive alerts when spending exceeds 90% of a budget, and preview reports before exporting them as CSV files.

I tested the API endpoints with Postman and checked the complete workflow from registration through recording transactions, receiving alerts, and exporting reports.
